# Sujeet Mathew Jose — Portfolio

Static site, no build step. Three files: `index.html`, `vision.html`, `sujeet-jose-cv.pdf`.

## Deploy to Vercel (5 minutes)

Option A — drag and drop:
1. Go to vercel.com/new
2. Drag this folder onto the page. Done. You get a `*.vercel.app` URL immediately.

Option B — GitHub (recommended, enables auto-deploy on every edit):
1. Create a new GitHub repo, push this folder to it.
2. vercel.com/new → Import the repo → Framework preset: "Other" → Deploy.
3. Every future push goes live automatically.

## Custom domain
Vercel dashboard → Project → Settings → Domains → add your domain,
then set the DNS records it shows you at your registrar (Cloudflare/Namecheap).

## Before sharing with anyone

filled in or deleted. The tags are visually loud on purpose.
